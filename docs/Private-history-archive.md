# Private history archive

The record of commit identifiers removed from the public branch is stored in the
[private GitHub archive](https://github.com/alastorid/waifufinder-history-archive/blob/main/secret%20commit%20hash.md).
Opening it requires GitHub access to that private repository. The identifiers are
omitted from this public source tree.

A private archive preserves the identifiers for the owner; it does not erase
copies that GitHub may retain from the earlier public history or copies in other
clones.
