WaifuFinder · First-time setup

Install WaifuFinder on your Mac.

For Apple silicon Macs with macOS 15 or later.

  1. Drag the app to Applications

    In the disk image window, drag WaifuFinder onto Applications. Wait for the copy to finish.

  2. Sign your copy on this Mac

    WaifuFinder’s developer does not have an Apple Developer ID certificate, so this release cannot include an Apple-verified developer signature. macOS may block it when you first open it.

    This one-time setup uses tools already on your Mac to apply a local signature to your installed copy. It needs no Apple developer account.

    What you are allowing

    xattr removes the download quarantine flag from WaifuFinder. codesign replaces its existing signature with a local one, including its bundled components. Both target only /Applications/WaifuFinder.app.

    These commands do not download a script, upload your files, or open the app. They do remove this app’s download protection. A local signature is not a safety check or approval from Apple. Continue only if you trust the official download; you can also inspect the source code.

    Copy the command: drag across all the text in the dark command block below to select it, then press ⌘C (Command-C).

    TERMINAL COMMAND
    xattr -dr com.apple.quarantine "/Applications/WaifuFinder.app" && codesign --force --deep --sign - "/Applications/WaifuFinder.app"

    Copy the entire command, even if it wraps onto several lines in this window.

    Paste into Terminal: press ⌘ Space, type Terminal, and press Return. In the Terminal window, press ⌘V (Command-V) to paste the command, then press Return to run it.

  3. Open WaifuFinder

    When Terminal finishes without an error, open Applications and double-click WaifuFinder. You can now eject the disk image. Next time, open the app as usual.

    If setup shows an error

    “No such file” means the app has not finished copying to Applications. A missing quarantine attribute can mean that flag is already cleared; you can run just the codesign part. For other errors, report the message rather than adding extra commands or administrator access.

This release is not signed with Apple Developer ID or notarized by Apple. Apple explains these protections. If macOS reports malware, do not use these steps to override that warning.
