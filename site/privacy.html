Privacy, plainly.

WaifuFinder analyzes video on your Mac. It does not send your videos, frames, tags or exports to us.

Your videos and results

By default, video analysis, tagging, previews and exports run locally in the app. If you enable remote WD Tagger, prepared frame images and tag results are exchanged with the Macs you connect over authenticated, encrypted connections. Your source video stays on the Mac that opened it. WaifuFinder has no account system, analytics or telemetry; files you export stay where you save them.

Model downloads

If you choose to install a model, the app downloads its files from a pinned Hugging Face repository and checks their hashes. That download sends ordinary connection information, such as your IP address, to Hugging Face and its file-delivery services. The app does not send them your video or analysis results. See Hugging Face's privacy policy.

This website

When the home page loads, a small script requests the latest release details from GitHub so the download button can show the current version. The request goes to GitHub's API. The site does not add analytics, advertising trackers or tracking cookies. GitHub hosts the site and API and handles connection data under its privacy statement.

Following a GitHub or Hugging Face link takes you to that service, where its own privacy terms apply.

Model licenses

Models have separate licenses from the app. PGTFormer has a non-commercial restriction, and its upstream weight files do not include a clear standalone license grant. Read the licensing record before using or redistributing model files.
