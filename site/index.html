02 / VISUAL SEQUENCECUOPT ROUTING SEARCH, PORTED TO METAL

Add a visual
sequence.

For photo collections, Minimal Visual Distance places similar-looking images beside one another. It approximates a shortest open path through the photos shown; reverse follows that same path backward. This feature adds a new way to browse after WaifuFinder has helped you find the frames you want.

01 / SEE

Describe each image.

Apple Vision supplies a visual fingerprint. Distances describe how different two images look.

02 / SEARCH

Find a smoother route.

Our Swift/Metal port of cuOpt’s 2-opt routing search tries several paths and evaluates improvements in parallel.

03 / BROWSE

Follow the sequence.

Every shown photo appears once. Reverse retraces the same path. Grouping is off by default and remains optional.

Optimized code · 768-dimensional synthetic vectors · four starting paths · 16 search iterations · includes distance-matrix construction. Excludes photo analysis and first shader compilation. M4 has not been measured.

What came from NVIDIA—and what we built for Mac

NVIDIA publishes cuOpt’s routing source under Apache 2.0. We adapted its 2-opt candidate search, ranked reductions and snapshot move execution into Swift and Metal. Apple Vision, Accelerate and Metal provide the native feature and execution pipeline. This is a specialized port of the routing search, with upstream attribution; the full CUDA solver is not running on macOS.

The objective is to reduce the total visual distance between neighboring photos, with no return edge from the end to the beginning. It is an approximate solution to an open-path traveling salesperson problem, rather than a guarantee of the global minimum. CPU and GPU distances are checked against Vision, including its squared-distance convention.

Videos can contain 200,000+ frames, but the 4× result is a solver measurement at 1,024 items. We have not benchmarked 200,000-item sequencing. The 16,384-item GPU cutoff is an implementation resource guard, not a collection limit: larger sets use the CPU fallback. A full distance matrix for 200,000 items would need about 149 GiB, so the implementation avoids allocating one. Analysis, filtering and sequencing have separate costs.

04 / DISTRIBUTED WD TAGGER PUT IDLE MAC MINIS TO WORK.

One queue. A pool of Apple silicon.

More Macs.
More frames in flight.

Connect compatible Macs and WaifuFinder sends tagging batches to the least-busy worker. Use the Mac with your video, remote Macs on your network, or both together. Add idle Mac minis to give the queue more capacity.

01 — LOCAL

Keep tagging here.

Run WD Tagger on the Mac with your video. Frames stay on that Mac.

02 — REMOTE

Put idle Macs to work.

Connected Macs run the model and return tag results. The video stays with the host Mac.

03 — LOCAL + REMOTE

Use the whole pool.

Include this Mac as a worker too. Batches flow across local and remote Macs at the same time.

More compatible Macs add concurrent batch capacity; the speedup depends on each Mac and the network. Remote workers receive prepared frame images over authenticated, encrypted connections. Matching WD Tagger labels are required to combine local and remote workers. How remote tagging works ↗
